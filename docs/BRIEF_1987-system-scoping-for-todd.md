# What's In the Original 1987 Program Files

A plain list of what's actually in the program's files, group by group. For
each group, here's what we believe it is. Where we're not sure, we say so in
one short line, not a long explanation.

## The eight industry versions

Every version (there are eight, one letter each: A, B, C, D, M, R, S, T) has
the same four files: one holds the questionnaire, one holds written risk and
fit-checking text, one calculates the scores and builds the report, and one
holds the underlying calculation formulas. That's the same pattern repeated
eight times.

A separate small file names which letter is which industry. Our reading of
it: A = Large Manufacturing, B = Large Service, C = Large Retail, D = Large
Restaurant, M = Manufacturing, R = Retail, S = Service, T = Restaurant. We
could be wrong about this — it's our read of one file, not confirmed against
your own memory of the system.

## The program launchers

Four files (named GPATHOR1 through GPATHOR4) plus two small companion files
look like how the whole program was packaged and started up. As far as we
can tell, they don't contain any additional content beyond the eight
versions above — just the startup/packaging layer.

## The Client Service Planning files

A separate group of six files forms a standalone program whose own title
screen calls it the "Client Service Planning System." Its own instructions
say it's for a consultant to fill out about a client, across six topics:
Development Stage, Strategy, Structure, Culture, Leadership Style, and
Client Relationship. We think that sixth topic, Client Relationship, is
actually about the consultant's own way of building trust with the client —
different from the other five, which are about the client's organization.

## The multi-rater comparison files

Three files contain what looks like a real, dated 1992 report comparing
eight different people's ratings of the same organization, showing where
they agreed and where they didn't.

## The fit-checking write-ups

Inside each version's risk file (mentioned above) there's a large amount of
written text — not just scores, but explanations of when certain
combinations of answers don't fit well together, what a "healthy" versus
"unhealthy" organization looks like on about thirty specific items, and a
description of what each growth stage's ideal way of being organized looks
like. This is real, complete, written content — the same kind of thing in
each of the eight versions.

## Individual client and consultant files

About twenty small files, each named with a consultant's or client's
initials, look like real saved assessments from actual past work — specific
people's actual results, not general content.

## The stage chart file

One file appears to describe the chart showing how an organization moves
between growth stages over time, including named points where one stage
turns into another.

## A couple of empty files

Two very small files appear to be leftover, empty print-output placeholders
with nothing in them.

## One thing we specifically checked and didn't find

We looked across every file above for anything related to nonprofit
organizations — a different letter, a different name, anything. We didn't
find it. If a nonprofit version exists, it isn't present in this set of
files.
